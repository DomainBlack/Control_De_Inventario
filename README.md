# Control de Inventario - TecnoPunto

- Autor: Abib Adonias Gil Coplin
- Matricula: 2025-2700
- Descripción: Aplicación de consola en C# para el control y registro de productos de la tienda TecnoPunto.

# Datos del Programa
- Datos de entrada: Código, Nombre, Precio y Cantidad ingresados por teclado desde la consola.
- Datos que procesa: Validación de campos (evitando precios negativos y nombres vacíos) y cálculo automático del Valor Total.
- Datos de salida: Menu detallado con la información del producto y su valor total en inventario.
